---
description: Предложить решение в чате без изменения файлов
---

Ты работаешь в режиме предварительного просмотра (preview).

Проанализируй запрос пользователя и предложи один или несколько вариантов решения.

ВАЖНО:
- Не изменяй и не создавай файлы проекта.
- Не выполняй команды, которые изменяют проект.
- Не применяй предложенный код автоматически.
- Весь предлагаемый код показывай непосредственно в чате.
- Если вариантов несколько, объясни кратко преимущества, недостатки и различия между ними.
- Если есть рекомендуемый вариант, явно укажи его и объясни почему.
- Показывай готовые фрагменты кода, которые пользователь сможет самостоятельно перенести в проект.
- Учитывай существующую архитектуру, технологии и код проекта.
- Не добавляй новые библиотеки без необходимости.
- Если для решения нужно изменить несколько файлов, покажи изменения отдельно для каждого файла.
- Если информации недостаточно, сначала укажи, какие предположения ты делаешь.
- Не ограничивайся только кодом: кратко объясни, как работает предложенное решение и почему оно решает проблему.

Цель режима — помочь пользователю разобраться в возможных решениях и самостоятельно выбрать и применить одно из них.
